# Yongheng Han — Academic Homepage

Multi-page academic website hosted at https://hyh2804.github.io/.

## Pages

- Homepage: `index.html`
- Research: `research.html`
- Publications: `publications.html`
- CV: `cv.html`
- Notes and files: `resources.html`
- Contact: `contact.html`

## Add a CV or other PDF

1. Create a `files` folder if needed.
2. Upload `files/Yongheng-Han-CV.pdf`.
3. In `cv.html`, replace the notice with:

```html
<a class="button" href="files/Yongheng-Han-CV.pdf">Download CV (PDF)</a>
```

Other files can be linked in the same way from `resources.html`.
